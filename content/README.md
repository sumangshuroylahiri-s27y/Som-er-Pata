# সাহিত্য রচনা সংরক্ষণাগার (Writings Archive)

এই ফোল্ডারে বাংলা সাহিত্যের বিভিন্ন সাহিত্য ধারার রচনাগুলো ক্যাটাগরিভিত্তিক ডিরেক্টরিতে সংরক্ষিত হবে:

- `kobita/` — কবিতা
- `golpo/` — গল্প
- `choto-lekha/` — ছোট লেখা
- `probandho/` — প্রবন্ধ
- `alochona/` — আলোচনা

## নতুন রচনা প্রকাশের নিয়মাবলী:

যেকোনো বিভাগে নতুন একটি `.md` ফাইল তৈরি করুন (যেমন: `content/kobita/amar-kobita.md`)। ফাইলের শীর্ষে YAML Frontmatter মেটাডাটা প্রদান করুন:

```markdown
---
title: "কবিতার শিরোনাম"
slug: "kobitar-shironam"
category: "kobita"
date: "2026-09-18"
excerpt: "কবিতার সংক্ষিপ্ত পরিচিতি বা দুই লাইন"
published: true
tags:
  - সাহিত্য
  - কবিতা
---

এখানে কবিতার মূল রচনা লিখুন।
প্রতিটি স্তবকের মাঝে একটি ফাঁকা লাইন রাখুন।
```

### প্রধান মেটাডাটা ফিল্ডসমূহ:
- `title`: রচনার শিরোনাম (বাংলা ভাষায়)
- `slug`: URL ফ্রেন্ডলি ইংরেজি স্লাগ (যেমন `amar-kobita`)
- `category`: ক্যাটাগরি আইডি (`kobita`, `golpo`, `choto-lekha`, `probandho`, `alochona`)
- `date`: রচনার তারিখ (YYYY-MM-DD ফরম্যাটে, যেমন `2026-09-18`)
- `published`: `true` হলে সর্বসমক্ষে প্রকাশিত হবে, `false` হলে ড্রাফট হিসেবে থাকবে
- `excerpt`: ঐচ্ছিক সংক্ষিপ্ত বিবরণ যা মূলপাতা ও সার্চ ফলাফলে প্রদর্শিত হবে
- `tags`: ঐচ্ছিক ট্যাগ তালিকা
